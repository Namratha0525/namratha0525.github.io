# Namrutha Daivajna’s portfolio

Open index.html to preview the site locally.

## Publish with GitHub Pages

1. Extract this zip. Upload index.html, style.css, script.js and the two assets (bloom.webp and Namrutha-Daivajna-Resume.pdf) to the root of a public GitHub repository. Keep the folder structure intact.
2. In Settings → Pages, choose Deploy from a branch. Select main and /(root), then save.
3. Open the published URL shown in Pages after deployment finishes.

The site works under a repository subpath. It uses local artwork, system fonts and plain HTML, CSS and JavaScript. The downloadable resume PDF and contact email will be public when the site is published.
